# Changelog

The version number is `APP_VERSION` near the top of the script in `index.html`. For every update,
raise it, add a line to the `CHANGES` list right below it (that list is what the app shows), and add
the same line here.

- **1.7.0** (Nov 13, 2026): Version number, list of changes and a Check for updates button.
- **1.6.0** (Nov 13, 2026): Flashcards can be browsed by swiping or with Previous / Next.
- **1.5.0** (Nov 13, 2026): Installable web app with its own icon. Works offline.
- **1.4.0** (Nov 13, 2026): Redesigned audio player.
- **1.3.0** (Nov 10, 2026): Icons. Audio guides are cached on the device after the first play.
- **1.2.0** (Nov 10, 2026): Audio study guides with memory tricks.
- **1.1.0** (Nov 10, 2026): Question bank encrypted with the access code.
- **1.0.0** (Nov 10, 2026): First version: flashcards, quiz, practice problems, missed-question review.
